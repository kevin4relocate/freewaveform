# FreeWaveform Demo

Fresh rebuild from zero. No legacy templates or old AnimeLoopMaker editor code.

## Current workflow

1. Upload local audio (MP3/WAV/M4A)
2. Upload an optional background image
3. Choose a waveform template, then fine-tune it manually
4. Edit Song Name, Artist / Channel, and add extra text layers
5. Drag the background, free waveform, and text directly on the canvas
6. Switch between 16:9 and 9:16
7. Export the full audio duration to WebM in real time

## Waveform features

- Brush Ring
- Smooth Ring
- Radial Bars
- Orbit Dots
- Center Wave
- Mountain Wave
- Bottom Wave
- Top Wave
- Top + Bottom
- Left Bars
- Right Bars
- Side Bars
- Circle, triangle, square, diamond, pentagon, hexagon, octagon, star, lotus and ink-blob shapes
- Manual color picker
- Auto Match Background
- Browser EyeDropper when supported
- Size, thickness, opacity, smoothing, reaction and glow controls
- Optional shape plate, secondary wave and glow

Free center waveforms can be dragged. Edge waveforms remain locked to their corresponding edges.

## Text

The editor starts with Song Name and Artist / Channel layers. Up to 10 total layers can be used. Each layer supports font, size, color, opacity, audio pulse on/off and direct canvas dragging.

Included font stacks favor Chinese / Guofeng and English typography, with Google Fonts loaded for Noto Serif SC, Noto Sans SC, Ma Shan Zheng, Playfair Display and Inter.

## Privacy

Uploaded audio and images stay local in the browser. There is no upload backend in this demo.
